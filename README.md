# projeto-js-basico
Aplicação web interativa com relógio em tempo real, validação de idade e alternador de tema claro/escuro usando HTML, CSS e JavaScript.
# Meu Primeiro Site com JavaScript 🚀

Aplicação web interativa desenvolvida para praticar conceitos fundamentais de HTML5, CSS3 e JavaScript (Vanilla JS).

---

## 📋 Funcionalidades

- **Box 1 (Horário Atual):** Exibe um relógio digital em tempo real que atualiza a cada segundo[cite: 4].
- **Box 2 (Entrada no Evento):** Campo interativo para validação de idade com verificação de números inteiros positivos e mensagens de permissão de acesso[cite: 4].
- **Box 3 (Aparência do Site):** Botão para alternar entre tema claro e escuro, com salvamento da preferência no navegador via `localStorage`[cite: 4].

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página[cite: 6].
- **CSS3:** Estilização com suporte a temas dinâmicos (Tema Escuro)[cite: 5].
- **JavaScript (ES6+):** Manipulação da DOM, funções de tempo (`setInterval`) e armazenamento local (`localStorage`)[cite: 4].
